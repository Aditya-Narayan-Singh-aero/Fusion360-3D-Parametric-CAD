# 3D Parametric CAD

Welcome to my repository for computer-aided design and parametric modeling! This repository tracks my progression as I build a strong foundation in 3D CAD modeling fundamentals using Autodesk Fusion 360, tailored for mechanical and aerospace engineering applications.

---

## 🚀 Projects Included

* **Standard 2x4 Lego Brick**
  * **Description:** A fully parametric 3D model of a classic 2x4 Lego brick designed with exact wall thickness optimization, top connection studs, and hollow under-side alignment tubes for interlocking functionality.
  * **Concepts Used:** Fully defined parametric sketches, base extrusions (join/cut), shell command, rectangular patterning, and edge filleting.
  * **Folder:** `Day01-Lego-Block/`

* **Glass Soda Bottle**
  * **Description:** A 3D model of a standard glass soda bottle created by calibrating a reference canvas image, tracing its outer profile, and revolving it around a central axis to achieve precise rotational symmetry and wall shelling.
  * **Concepts Used:** Canvas image insertion & calibration, centerline construction, spline sketch modeling, revolve operation, and uniform shelling.
  * **Folder:** `Day02-Soda-Glass-Bottle/`

* **Standard Paperclip**
  * **Description:** A precise 3D model of a standard paperclip created by defining a continuous multi-arc 2D path and sweeping a circular cross-section along the trajectory.
  * **Concepts Used:** Tangent arc construction, continuous line-arc pathing, sweep feature, and profile orientation control.
  * **Folder:** `Day03-Paperclip/`
